Import / Export

Administration des contrats de mapping entre les données extraites des documents et le modèle Grist.

À quoi sert le mapping ?

Le mapping est le contrat entre l’analyse d’une fiche Produit et Grist. À gauche figurent les informations que l’IA doit identifier dans le document ; à droite les colonnes de Fonctionnalites. Les traits indiquent où chaque valeur doit être écrite. Vous pouvez les créer par glisser-déposer, remapper un champ vers une autre colonne et supprimer une liaison avec ×, le bouton Délier, la touche Suppr, un double-clic ou un clic droit sur le trait. Une référence Ref est recherchée dans sa table référente et peut être créée si elle n’existe pas.

Important : une valeur absente du document reste null et n’efface pas une valeur existante lors d’une mise à jour. Modifier ce mapping ne modifie pas le schéma Grist.
